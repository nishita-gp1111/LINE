# トークの文章テンプレート

トーク入力欄の「📝 テンプレート」から、名前・本文を検索して入力欄へ差し込めます。
選択は送信ではありません。本文を確認・編集し、通常の「送信」で送ります。
入力済みの下書きは残し、改行して末尾へ追加します。合計5000文字を超える場合は追加しません。

owner/adminは同じパネルで新規作成・編集できます。新規作成の本文には現在の下書きを入れます。
組織共通の文面として保存するため、顧客個人情報を含めないでください。
operatorは選択のみ、viewerは利用不可です。既存の権限と送信停止・ブロック制御を維持しています。
並び順・無効化・削除はパネル内のリンクから既存の設定画面で行えます。

## 保存と安全性

- 既存の`quick_reply_templates`と認証済み`/api/inbox/quick-replies`を再利用。migration・環境変数の追加は不要。
- 組織IDはサーバーの認証情報から決定。更新はowner/adminかつ信頼されたOriginのみ。
- 取得結果はprivate/no-store。非表示テンプレートは選択肢へ出さず、開くたびに再取得。
- 同名保存は409。内部DBエラーは公開せず、フォームと下書きは失敗時にも保持。
- 作成・選択・編集はLINE APIを呼ばず、送信フラグも変更しない。
