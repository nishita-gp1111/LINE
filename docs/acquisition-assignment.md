# 流入URLごとの担当者自動振り分け

## 共通アカウントで利用する場合

「流入経路URL」→ 各URLの「担当者の自動振り分け」に担当者名を1行1名で入力し、保存します。
個別のログインアカウント作成は不要です。名前の登録で権限が追加されることはありません。

面談URL `/add/meeting` の設定順序：今福 → 志水 → 魚井 → 西田 → 先頭へ。
アンケート経由・HP経由のURLは、設定を有効化しなければ振り分けません。

## 担当者別の面談URL

共通URLを残したまま、以下の専用URLから登録した未担当の顧客は指定担当へ固定割り当てします。
管理画面 `/admin/acquisition` の「担当者別の面談URL」からコピーできます。

| 担当者 | URL |
| --- | --- |
| 今福 | https://line-gp-1111.vercel.app/add/meeting-imafuku |
| 志水 | https://line-gp-1111.vercel.app/add/meeting-shimizu |
| 魚井 | https://line-gp-1111.vercel.app/add/meeting-uoi |
| 西田 | https://line-gp-1111.vercel.app/add/meeting-nishita |

4本とも「面談から流入」タグを付与します。個別ログインは不要で、権限は増えません。
対応はサーバー側の許可リストで固定し、URLから任意の担当者名を指定できません。
専用URLは共通URLの順番を進めず、共通の振り分けを停止しても利用できます。
既存担当者・最初の割り当ては維持します。URLを開いただけではなく、LINE本人・友だち確認後（予備方式では登録メッセージ受信後）に確定します。
このURLは本人専用の認証リンクではなく、顧客へ共有する公開リンクです。

- LIFFの本人・友だち確認後に、担当者を割り当てます。予備の登録メッセージ経由も同じ処理です。
- ログイン担当者・名前担当者のどちらも、既に設定済みなら上書きしません。
- 同じ顧客の再アクセス、別URLでの再登録、手動で担当者を変更・解除した後の再アクセスでも再割り当てしません。
- 停止中は順番を進めません。同じ名簿で再開すると続きから振り分けます。
- 名簿の変更・並べ替え後は先頭から開始します。過去の顧客の担当者は変わりません。
- トークの担当者欄から、手動変更・未担当への解除も可能です。「自分の担当」はログイン担当の絞り込みのため、共通ログインでの各担当者名とは別です。
- LINEメッセージ送信やリッチメニュー変更は行いません。

## 公開順序

1. 新規migration `20260919010000_acquisition_assignment.sql` のみを適用。過去のmigrationは編集しない。
2. アプリをデプロイ。DB未更新の場合は設定画面が警告を表示し、保存できない。
3. 本番「流入経路URL」で担当者名と順番を保存して有効化。migration自体は自動有効化しない。
4. 既存顧客の一括再割り当ては実行しない。停止する場合は有効チェックを外して保存する。

専用4本の追加時は、上記の基盤適用後に `20260919020000_staff_acquisition_links.sql` を先に適用してからアプリをデプロイします。
これは割り当て関数のみの置換で、既存のルール・順番・顧客データは変更しません。共通URLの設定画面から専用URLの固定担当を変更することはできません。
DB未更新時、専用URLの登録処理は成功扱いにせず安全に停止します。

DBでは振り分けルールと会話の行ロック、顧客単位の一意な決定履歴で重複を防止する。
担当者名・順番・履歴は組織ごとに分離し、設定APIはowner/adminのみ利用可能。

## 検証

`pnpm test` はPGlite上で新migrationと既存の会話作成関数を実行し、4名の循環・40件の重複呼び出し・担当維持・手動解除後の再アクセス・組織境界・RPC権限・停止再開を検証する。
PGliteは単一接続で処理するため、複数のPostgreSQL接続間のロック競合テストとは区別する。
`pnpm test:e2e` は設定の保存・再読込・停止、モバイルの横溢れを検証する。
専用URLについては、4名の固定割り当て、共通順番非消費、停止中の動作、担当者維持、組織境界、LIFFと予備メッセージの経路引き継ぎ、DB未更新時の失敗を検証します。
ブラウザテストは4本のコピーと公開ページ、PCのQR宛先、スマートフォン表示を検証します。実際の友だち追加・本番顧客への送信は自動テストで行いません。
